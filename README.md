# Comunidade Familia Em Cristo — Sistema de Louvor e Palavra

Sistema de registro de hinos e referências bíblicas para os cultos da igreja.

## Como rodar localmente

**Pré-requisitos:** Node.js

1. Instale as dependências:
   `npm install`
2. Rode o projeto:
   `npm run dev`

## Build de produção

`npm run build`
